# Security

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately through
[GitHub security advisories for this repository](https://github.com/Dream-byte-lab/desktop/security/advisories/new).

Include what you found, how to reproduce it, and which Linerave version you tested.
Credit is given in the release notes unless you'd rather stay anonymous.

## Supported versions

Only the latest Linerave release gets security fixes.

## Independence from upstream

Linerave is maintained independently of upstream Liner, including for security.
Security fixes are written by this fork and shipped in its own releases, on its own
schedule; this fork does not receive security updates, patches, or over-the-air
bundles from upstream, and upstream's bundle update channel is disabled in this
build. Reports sent to upstream do not reach this fork — please use the route above.
